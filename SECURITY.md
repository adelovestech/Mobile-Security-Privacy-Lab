# Responsible security and privacy handling

This repository is educational documentation; it does not host a production service or solicit vulnerability submissions for Apple, Google, or third-party apps.

**Do not post real credentials, active exploits against third parties, sensitive captures, or identifying device metadata in issues or pull requests.** Report security vulnerabilities in third-party products through the relevant vendor's official disclosure channel.

If you accidentally commit a secret, revoke or rotate it promptly. Deleting a line in a later commit does not remove it from Git history. Seek appropriate help to remediate exposed history.

All labs must use assets you own or have explicit authorization to test.
