# Official sources and scope

Checked for this starter release on **2026-11-09**.

| Source | What it supports | Scope caution |
|---|---|---|
| [Apple — Control what you share](https://support.apple.com/en-euro/guide/iphone/iph6e7d349d1/ios) | iPhone permission and privacy settings | UI differs by iOS version |
| [Apple — App access controls](https://support.apple.com/en-mide/guide/iphone/iph251e92810/ios) | App permissions and App Privacy Report | Does not establish malicious behavior |
| [Google — Android app permissions](https://support.google.com/android/answer/9431959) | Android permission management | OEM UI variations expected |
| [Google — Privacy Dashboard](https://support.google.com/android/answer/13530434) | Recent permission-access visibility | Not equivalent to a full forensic log |
| [Google — Security and privacy](https://support.google.com/android/answer/13985942) | Android security/privacy settings | Availability varies by version |
| [NIST SP 800-124 Rev. 2](https://csrc.nist.gov/pubs/sp/800/124/r2/final) | Enterprise mobile risk and management guidance | Consumer lab is not a NIST audit |
| [OWASP MASVS](https://mas.owasp.org/MASVS/) | Mobile **application** security verification | Not a device-settings certification |

Reference vendor documentation directly and review it before publishing changes. Where direct observations disagree with documentation, report the OS/build and observed discrepancy without claiming a universal result.
